### 2.3 配置确定流程

本项目的最终训练配置不是一次性拍定，而是按以下顺序逐步确定：

1. 先设定一套可运行、可复现的基础配置，保证主流程能够稳定完成训练并产出结果；
2. 在基础配置上进行消融实验，分析数据增强、激活函数、正则项、学习率调度等组件是否真正带来收益；
3. 根据消融结果固定结构与训练策略，得到新的默认配置；
4. 在该默认配置上进一步进行参数对比实验，重点比较学习率等连续超参数；
5. 最后使用“消融筛出的最优配置 + 对比筛出的最优参数”重新运行主训练，并将该结果作为当前仓库的默认主模型结果。

采用这一流程的原因是：学习率等超参数的最优值依赖于模型结构、增强策略和正则化设置；如果先在旧配置上调参，再改结构，先前得到的“最优参数”往往会失效。因此，本项目将“先消融、后调参、再最终训练”作为主要实验逻辑。

## 3. 第一部分：纯 numpy 反向传播神经网络

### 3.1 核心实现思路

核心代码位于 `models/part1/nn.py`。整个实现围绕一个 `NeuralNetwork` 类展开，主要包含以下部分。

#### 3.1.1 参数与初始化

网络用两个列表保存所有层的参数：

- `self.W`：每层权重矩阵
- `self.b`：每层偏置

初始化时根据激活函数选择不同缩放系数：

- 若为 `relu` / `leaky_relu`，采用近似 He 初始化的尺度 `sqrt(2 / fan_in)`（对 `leaky_relu` 严格应为 `sqrt(2 / ((1+a²) × fan_in))`，此处忽略负斜率系数 a=0.01，误差可忽略不计）
- 若为 `tanh` / `sigmoid`，采用较保守的 `sqrt(1 / fan_in)`

这样做的目的是控制前向传播过程中各层输出的方差，减轻梯度爆炸或梯度消失。

同时，代码还维护了：

- `self.vW`
- `self.vb`

用于实现带动量的 SGD 更新。

#### 3.1.2 前向传播

前向传播函数 `forward` 的实现流程如下：

1. 将输入 `X` 记为第一层激活值 `A[0]`
2. 对每一层执行线性变换 `z = a @ W + b`
3. 若为隐藏层，则经过激活函数得到新的激活值
4. 若为输出层，则根据任务类型使用：
   - 回归：`linear`
   - 分类：`softmax`
5. 将每层的激活值和隐藏层的 `z` 值分别缓存到：
   - `self._A`
   - `self._Z`

缓存这些中间结果是为了在反向传播中直接复用，避免重复计算。

#### 3.1.3 损失函数

代码支持两类损失：

- MSE：用于回归任务
- Cross Entropy：用于分类任务

其中分类任务中，输出层采用 `softmax`，损失采用交叉熵。实现中对概率做了裁剪，避免出现 `log(0)` 导致数值溢出。

#### 3.1.4 反向传播

`backward` 的实现流程如下：

1. 先计算输出层误差项 `delta`
   - 若是分类任务，利用 `softmax + cross entropy` 的联合导数，直接得到：
     `(out - y_true) / m`
   - 若是回归任务，则使用 MSE 对输出求导
2. 从最后一层向前循环：
   - 计算当前层梯度 `dW` 和 `db`
   - 若开启 L2 正则，则在 `dW` 上额外加 `weight_decay * W`
   - 若不是第一层，则继续将误差向前传播
3. 所有层梯度求出后，再执行梯度裁剪
4. 最后使用 SGD + Momentum 更新参数

这一实现将“求导”和“参数更新”放在同一个流程中，结构简单清晰，也满足项目要求。

#### 3.1.5 训练流程

`train` 函数完成统一训练流程：

1. 每轮打乱数据
2. 按 batch 依次前向、计算损失、反向更新
3. 记录训练损失与验证损失
4. 按设定步长衰减学习率

这个训练框架同时被回归任务和分类任务复用，只需传入不同的输出层、损失函数和超参数即可。

### 3.2 回归任务：拟合 sin(x)

#### 3.2.1 实现思路

代码位于 `models/part1/regression.py`。回归任务的主要设计如下：

- 随机生成训练点 2000 个、测试点 500 个
- 输入先除以 `pi`，归一化到 `[-1, 1]`
- 网络结构设为 `1-128-64-64-1`
- 隐藏层激活使用 `tanh`
- 输出层使用线性输出
- 损失函数为 MSE

这里选择 `tanh` 的原因是 `sin(x)` 本身是连续、平滑、中心对称的非线性函数，`tanh` 的函数形状和这种目标更匹配。

#### 3.2.2 实验结果

- 测试 MAE：`0.000778`
- 测试 MSE：约 `1e-6`

项目要求平均误差小于 `0.01`，实验结果远优于要求。

#### 3.2.3 结果分析

该任务已经达到充分收敛状态，说明：

1. 当前网络宽度与深度足以表达目标函数；
2. 输入归一化和 `tanh` 激活的选择是合理的；
3. 若只追求满足项目要求，训练轮数还可以适当减少。

### 3.3 12 类手写汉字分类任务（BP）

#### 3.3.1 数据处理与划分

分类代码位于 `models/part1/classification.py`。数据读入后被展平成 `784` 维向量。标签经过 `one_hot` 编码，以便直接用于交叉熵损失的计算。

训练集与验证集采用按类别分层划分。具体做法是：

1. 对每个类别分别取出所有样本下标
2. 在类别内部打乱
3. 按 `15%` 比例划分验证集
4. 将所有类别的训练下标和验证下标拼接

这样做可以避免简单随机划分带来的类别比例波动。

#### 3.3.2 数据增强实现

当前默认主模型 `models/part1/classification.py` 的增强实现是：

- 不做水平翻转
- `np.roll` 的 ±2 像素平移

说明：根据最新 BP 消融结果，默认配置已切换为 `bp_base`，即关闭翻转、保留平移增强；消融脚本中的“可控开关翻转 + 零填充平移 `translate_with_padding`”仍用于实验分析。

#### 3.3.3 网络与训练流程

BP 分类模型采用：

- 结构：`[784, 512, 256, 128, 12]`
- 激活：隐藏层 `ReLU`，输出层 `Softmax`
- 损失：交叉熵
- 优化：SGD + Momentum
- 正则：L2 weight decay
- 学习率策略：每 30 epoch 乘 `0.7`

训练循环由 `classification.py` 自行实现，主要步骤如下：

1. 先对训练集做增强
2. 再打乱 batch 顺序
3. 对每个 batch 调用 `model.forward`
4. 计算损失后调用 `model.backward`
5. 每轮结束后计算训练准确率与验证准确率
6. 若验证准确率提升，则保存当前最优参数
7. 训练固定轮数后输出最优模型参数与曲线

这部分没有复用 `nn.py` 中的统一 `train`，而是单独实现了更细粒度的训练流程，原因是分类任务需要在每轮结束时显式计算准确率并维护最佳模型。

BP 网络在该任务上已经达到较高精度，但仍存在明显结构局限：

3. 对形状相近类别的区分能力不如卷积网络。

因此，BP 可以作为较强基线，但不是该任务最优结构。

## 4. 第二部分：卷积神经网络（CNN）

### 4.1 数据管线实现

CNN 代码位于 `models/part2/cnn.py`。数据处理部分由三个模块组成：

1. `ChineseCharDataset`
   - 负责扫描目录
   - 保存 `(path, label)` 对
   - 在 `__getitem__` 中读取灰度图并应用变换

2. `stratified_split_indices`
   - 按类别收集样本下标
   - 使用固定随机种子打乱
   - 在每个类别内部按比例划分训练集和验证集

3. `get_dataloaders`
   - 构造训练变换和验证变换
   - 创建两个带不同 transform 的数据集
   - 用 `Subset` 根据分层下标建立训练集和验证集
   - 返回 `DataLoader`

与原始随机切分相比，分层划分更利于保证评估稳定性。

### 4.2 模型实现思路

CNN 的结构由两个类组成：

#### 4.2.1 `ConvBlock`

每个卷积块包含：

- `Conv2d`
- `BatchNorm2d`
- `ReLU`
- 可选 `MaxPool2d`

这种写法可以减少重复代码，也便于快速搭建多层网络。

#### 4.2.2 `SimpleCNN`

整体结构为：

```text
Conv(1→32) + BN + ReLU + Pool
Conv(32→64) + BN + ReLU + Pool
Conv(64→128) + BN + ReLU
GAP
FC(128→256) + ReLU + Dropout
FC(256→12)
```

实现思路如下：

1. 前两层卷积通过池化逐步降低空间分辨率；
2. 第三层卷积继续提取高层特征，但不再池化，避免特征图过早缩小；
3. 通过 `AdaptiveAvgPool2d(1)` 做全局平均池化，将二维特征图压缩为长度为 128 的特征向量；
4. 最后用两层全连接完成分类。

这种结构参数量不大，但已足以处理 28x28 的小尺寸字符图像。

### 4.3 训练实现思路

训练部分拆分为三个函数：

- `train_one_epoch`
- `evaluate`
- `run`

其中：

1. `train_one_epoch` 在训练模式下完成一轮参数更新
2. `evaluate` 在 `torch.no_grad()` 下进行验证
3. `run` 负责组织整体训练流程，包括：
   - 创建数据加载器
   - 构建模型
   - 定义损失函数、优化器和学习率调度器
   - 逐轮训练和验证
   - 保存最佳模型
   - 记录并绘制训练曲线
   - 在最优模型上生成混淆矩阵

优化器采用 `AdamW`，学习率调度采用 `CosineAnnealingLR`。这种组合在中小规模图像分类任务中通常具有较好的稳定性。

### 4.4 CNN 实验结果

最新主模型训练日志（`train/train_log/train_part2.log`）结果为：

- 最优验证准确率：`99.91%`
- 末轮验证准确率：`99.8%`（epoch 100）
- 训练配置：`epochs=100, batch_size=64`

说明在完整训练预算下，CNN 稳定达到接近 `99.8%` 的验证精度，显著优于 BP 基线。

### 4.6 CNN 参数对比实验

同样地，还补充进行了 CNN 学习率参数对比实验，脚本位于 `contrast/contrast_part2/run_contrast_part2.py`。实验设置为：

- 对比参数：`learning_rate ∈ {5e-4, 1e-3, 2e-3}`
- `epochs=100`
- `batch_size=64`
- 其余设置固定为：`AdamW`、`weight_decay=1e-4`、`label_smoothing=0.1`、`dropout=0.5`

本轮实验在 GPU 上完成，运行设备记录为 `cuda`。

结果如下（来自 `contrast/contrast_part2/contrast_results_part2/leaderboard.csv`）：

| 学习率 | 最优验证准确率 | 达峰 epoch | 末轮验证准确率 |
|---|---:|---:|---:|
| `1e-3` | `99.73%` | 41 | `99.64%` |
| `2e-3` | `99.73%` | 42 | `99.73%` |
| `5e-4` | `99.64%` | 56 | `99.46%` |

可以看到，`1e-3` 与 `2e-3` 的峰值验证准确率并列最高，而 `5e-4` 略低。进一步看末轮验证准确率，`2e-3` 高于 `1e-3`，因此在最新配置下更适合作为默认学习率。

因此，代码仓库中 `models/part2/cnn.py` 的默认学习率调整为 `2e-3`；同时根据最新消融结果，默认 `weight_decay` 调整为 `0.0`。

### 4.7 消融分析

可以得到以下结论：

1. 最新重跑中，`no_weight_decay` 以 `99.91%` 明显高于 `full` 的 `99.73%`，说明当前默认 `weight_decay` 可以去掉。
2. `no_dropout` 与 `no_scheduler` 都达到 `99.82%`，说明这两项也不是决定性因素，但收益不如“去掉 weight decay”稳定。
3. `no_aug` 与 `full` 持平，`no_label_smoothing` 最低，说明标签平滑仍更值得保留，而数据增强收益较弱但无明显负效应。
4. 因此当前默认 CNN 配置保留：增强、Dropout、scheduler、label smoothing，并去掉 `weight_decay`。

从结果上看，CNN 明显优于 BP。原因主要有三点：

1. 卷积网络能直接建模局部笔画结构；
2. 卷积核共享参数，学习效率更高；
3. 汉字识别高度依赖空间布局，而这一信息在全连接展平输入中被削弱。

因此，在该任务上，卷积结构比纯全连接结构更合理。
