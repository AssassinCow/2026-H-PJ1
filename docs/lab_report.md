## 3. 第一部分：纯 `numpy` 反向传播神经网络

### 3.1 核心目标

第一部分的关键不是“调用一个现成神经网络”，而是从零实现以下链条：

1. 参数初始化；
2. 前向传播；
3. 损失计算；
4. 反向传播求梯度；
5. 基于梯度更新参数。

核心代码位于 `models/part1/nn.py`。整个实现使用 `NeuralNetwork` 类统一管理多层全连接网络，使网络层数、每层宽度、激活函数、损失函数、学习率、正则项等都可以直接配置。这一点对应了项目说明中对“可扩展性与可调性”的要求。

### 3.2 反向传播算法原理与代码实现

#### 3.2.1 前向传播的计算逻辑

对于第 `l` 层，全连接层的基本形式为：

```text
z[l] = a[l-1] W[l] + b[l]
a[l] = f(z[l])
```

其中：

- `a[l-1]` 是上一层输出；
- `W[l]`、`b[l]` 是本层参数；
- `z[l]` 是线性变换结果；
- `f` 是激活函数。

代码中，隐藏层支持 `relu`、`leaky_relu`、`tanh`、`sigmoid`，输出层根据任务类型使用：

- 回归：线性输出；
- 分类：`softmax`。

为了执行反向传播，前向过程中必须保留中间量。实现中将各层激活值保存到 `self._A`，将隐藏层线性输出保存到 `self._Z`。这样在求导时可以直接复用这些量，而不需要重复做前向计算。

#### 3.2.2 反向传播为什么可以逐层求解

神经网络训练的本质，是最小化损失函数对所有参数的值。由于每层输出都依赖前一层输出，因此需要用链式法则逐层传递梯度。

若输出层误差项记作 `delta`，则有：

```text
dW[l] = a[l-1]^T delta[l]
db[l] = sum(delta[l])
delta[l-1] = (delta[l] W[l]^T) ⊙ f'(z[l-1])
```

这三步对应了反向传播最核心的思想：

1. 当前层参数梯度由“前一层激活”和“当前层误差”共同决定；
2. 偏置梯度本质上是当前层误差在 batch 维度上的求和；
3. 误差会先通过权重矩阵传回前一层，再乘以激活函数的导数。

这也解释了为什么激活函数选择会影响训练难度：如果导数长期过小，误差信号在多层传播中会迅速衰减，从而出现梯度消失；如果数值过大，则可能引发梯度爆炸。当前实现中的梯度裁剪和初始化策略，都是围绕这个问题展开的稳定化设计。

#### 3.2.3 损失函数与输出层的对应关系

项目包含回归和分类两种任务，因此损失函数不能混用。

- 回归任务使用 MSE，因为目标是逼近连续数值；
- 分类任务使用 `softmax + cross entropy`，因为目标是学习类别概率分布。

分类任务里，`softmax` 将输出映射为概率，交叉熵用于度量预测分布与真实分布的差异。实现中直接使用了 `softmax + cross entropy` 的联合导数：

```text
delta = (y_pred - y_true) / m
```

这样既简洁，也具有较好的数值稳定性。代码中另外对概率做了裁剪，以避免 `log(0)`。

#### 3.2.4 初始化、动量与梯度裁剪的作用

当前实现不是简单地“随机给值”，而是根据激活函数选择初始化尺度：

- `relu` / `leaky_relu` 使用近似 He 初始化；
- `tanh` / `sigmoid` 使用更保守的 `sqrt(1 / fan_in)`。

这样做的原因，是尽量保持层间信号方差稳定，避免网络一开始就进入饱和区。

在参数更新上，代码使用 `SGD + Momentum`：

```text
v = momentum * v + lr * grad
param = param - v
```

动量的作用不是改变最优解，而是减少参数在陡峭方向上的震荡，并在方向较稳定时加快前进。对于本项目这类中小规模任务，它比纯 SGD 更容易得到平滑的收敛曲线。

此外，代码还加入了全局梯度范数裁剪。它的意义在于：当个别 batch 产生异常大梯度时，先把整体梯度缩放到安全范围，再执行更新，防止训练被一次不稳定更新破坏。

### 3.3 回归任务：拟合 `sin(x)`

#### 3.3.1 网络设计思路

回归代码位于 `models/part1/regression.py`。该任务使用的设置为：

- 训练样本 2000 个，测试样本 500 个；
- 输入先除以 `pi`，归一化到 `[-1, 1]`；
- 网络结构：`1-128-64-64-1`；
- 隐藏层激活：`tanh`；
- 输出层：线性；
- 损失函数：MSE。

这里的设计逻辑是明确的。

第一，`sin(x)` 是平滑、连续、奇对称函数，而 `tanh` 也是平滑且中心对称的非线性函数。相比 ReLU，`tanh` 在拟合这类连续函数时往往更容易形成平滑曲线，而不会在局部产生明显折线感。

第二，输入缩放到 `[-1, 1]` 后，数值范围与 `tanh` 的有效响应区间更匹配。若直接输入 `[-pi, pi]`，前几层更容易进入激活函数饱和区，导致梯度效率下降。

第三，该任务只有一维输入，网络不需要很深；但适当增加宽度可以提高对非线性曲线的逼近能力，因此采用了“较宽、不过深”的结构。

#### 3.3.2 实验结果

- 测试 MAE：`0.000778`
- 测试 MSE：约 `1e-6`

项目要求平均误差小于 `0.01`，当前结果明显优于要求。

#### 3.3.3 结果分析

这一结果说明，当前模型已经足够表达 `sin(x)` 的主要形状。更重要的是，它验证了三个判断：

1. 对连续函数逼近，输入尺度与激活函数形状的匹配非常关键；
2. 在目标函数较平滑时，`tanh` 比 ReLU 更适合作为隐藏层非线性；
3. 对简单低维任务，网络深度并不是越大越好，合适的结构比盲目堆层更重要。

### 3.4 12 类手写汉字分类任务（BP）

#### 3.4.1 数据表示与任务难点

分类代码位于 `models/part1/classification.py`。输入图像会被展平成 `784` 维向量，然后送入全连接网络。

这种表示方式实现简单，但也直接带来结构缺陷：图像中“相邻像素”的空间关系在展平后不再显式保留。例如，字符的一段横画和一段竖画在二维图像里有明确的局部组合关系，但在一维向量中，这种局部结构只能依靠全连接层间接学习。因此，BP 网络虽然能够做分类，但在图像任务上先天不如卷积网络自然。

#### 3.4.2 数据划分与增强策略

训练集和验证集使用按类别分层划分，每类取约 `15%` 作为验证样本。

主模型默认增强方式为：

- 关闭水平翻转；
- 保留 `±2` 像素随机平移。

这一设计不是随意选择，而是由字符任务本身决定的。

随机平移通常是合理增强，因为书写位置的轻微偏移不改变字符类别；模型如果能对这种位移保持稳定，就能学到更稳健的笔画布局表示。

但水平翻转对汉字并不总是语义保持的变换。对于自然图像，左右翻转往往不改变“猫”“狗”这类类别；而对字符来说，左右结构和笔画朝向本身就是判别信息的一部分。因此，翻转会把“合法样本”变成“偏离真实书写分布的伪样本”，从而扰乱决策边界。

#### 3.4.3 BP 分类网络设计

主模型结构为：

- 输入维度：`784`
- 隐藏层：`512 -> 256 -> 128`
- 输出层：`12`
- 激活函数：隐藏层 `LeakyReLU`
- 输出层激活：`Softmax`
- 损失函数：交叉熵
- 优化：`SGD + Momentum`
- 正则化：L2 weight decay
- 学习率策略：每 `30` 轮乘 `0.7`

这里的设计思路有以下几点。

第一，网络宽度从 `512` 逐层收缩到 `128`，本质上是在做逐级特征压缩：前层负责接收较高维的原始像素组合，中间层逐步提炼更抽象的判别特征，最后映射到 12 个类别。

第二，隐藏层选择 `LeakyReLU` 而不是 `sigmoid` / `tanh`，主要是出于优化稳定性考虑。对这种多层分类网络，`sigmoid` 和 `tanh` 更容易出现梯度衰减；标准 ReLU 虽然训练快，但会产生“负半轴完全截断”的现象，而 `LeakyReLU` 保留了一小部分负区间梯度，可以降低神经元“失活”的风险。

第三，学习率分段衰减的意义不是“后期一定更准”，而是让模型在训练前期快速找到较优区域，在后期用更小步长做精细调整。对 BP 这类没有 BatchNorm 的多层全连接网络而言，这种简单调度通常比固定学习率更稳。

#### 3.4.4 实验结果

主训练结果为：

- 训练配置：`epochs=150, batch_size=128`
- 最优验证准确率：`96.76%`
- 末轮验证准确率：`95.3%`

该结果说明，纯全连接 BP 网络已经能够较好地区分 12 类手写汉字，但后期末轮精度略低于峰值，也提示模型仍存在一定过拟合或训练震荡。

#### 3.4.5 消融实验分析

BP 消融结果如下：

| 配置 | 最优验证准确率 | 达峰 epoch |
|---|---:|---:|
| `bp_leaky_relu`：`flip=False, shift=2, leaky_relu, wd=1e-4` | `97.21%` | 135 |
| `bp_base`：激活改为 `relu` | `97.12%` | 144 |
| `bp_no_wd`：去掉权重衰减 | `97.03%` | 150 |
| `bp_flip_on`：开启水平翻转 | `96.67%` | 129 |
| `bp_no_shift`：不做平移增强 | `91.37%` | 47 |

这个结果有很强的解释意义。

首先，去掉平移增强后准确率下降最明显，说明对该任务而言，模型需要学到“字符整体位置轻微变化不应改变类别”的不变性，而仅靠全连接结构本身并不容易自动获得这种能力。平移增强实际上是在用数据先验补偿结构先验的不足。

其次，开启水平翻转后性能下降，进一步证明字符识别与自然图像分类不同，增强策略必须服从任务语义，而不能机械套用通用模板。

再次，`LeakyReLU` 相比 `ReLU` 略优，说明在当前网络深度和学习率设置下，保留负半轴梯度确实有助于优化；但提升幅度不大，也说明激活函数不是限制 BP 性能的决定性因素，结构本身才是更大的瓶颈。

最后，去掉 weight decay 影响相对有限，表明对这个规模的数据集而言，BP 模型的主要矛盾不在参数量过大，而在于输入表示方式较弱。

#### 3.4.6 参数对比实验分析

BP 学习率对比结果如下：

| 学习率 | 最优验证准确率 | 达峰 epoch | 末轮验证准确率 |
|---|---:|---:|---:|
| `1e-2` | `97.03%` | 150 | `97.03%` |
| `2e-2` | `96.85%` | 133 | `96.40%` |
| `5e-3` | `95.86%` | 146 | `95.41%` |

可以看出，`1e-2` 在当前结构上更平衡。

- `5e-3` 收敛偏慢，说明步长略小，训练预算没有被充分利用；
- `2e-2` 虽然前期推进更快，但后期稳定性稍差；
- `1e-2` 在 150 轮时仍能继续上升到最优，说明它更适合当前模型的优化尺度。

#### 3.4.7 阶段小结

BP 网络的价值在于，它完整展示了反向传播从数学形式到代码实现的全过程，也证明了纯 `numpy` 实现足以完成中等规模分类任务。但从结构上看，它对二维空间模式的表达能力有限，因此可以作为有效基线，却不是图像分类任务的最优选择。

## 4. 第二部分：卷积神经网络（CNN）

### 4.1 为什么分类任务更适合 CNN

与全连接网络相比，卷积网络更适合手写字符识别，原因不只是“大家都这么做”，而是因为它与图像的统计结构天然匹配：

1. 局部连接：字符由笔画局部组合而成，卷积核可以直接提取局部边缘、拐点、交叉等模式；
2. 参数共享：同一类笔画模式可能出现在图像不同位置，共享卷积核可以减少参数冗余；
3. 层级特征：浅层卷积提取边缘和纹理，中层组合成笔画和偏旁，高层再形成类别判别特征。

对于 `28 x 28` 的小尺寸字符图像，这种结构先验比“把图像展平后再全连接”更加合理。

### 4.2 数据管线设计

CNN 代码位于 `models/part2/cnn.py`。数据处理包括三部分：

1. `ChineseCharDataset` 负责扫描目录并读取图像；
2. `stratified_split_indices` 负责按类别分层切分；
3. `build_dataloaders` 负责构造训练/验证数据集与 `DataLoader`。

训练阶段使用的数据增强包括：

- 随机水平翻转；
- 随机仿射变换：旋转、平移、缩放；
- 标准化到 `[-1, 1]` 附近。

虽然“水平翻转”在 BP 部分不利，但 CNN 当前训练中配合更强的卷积特征提取与更丰富的仿射扰动，整体仍可达到很高精度。这里也说明一个重要事实：增强策略是否有效，不仅取决于数据本身，还取决于模型表达能力与整体训练配方。单独讨论某个增强是否“绝对正确”往往并不充分。

### 4.3 CNN 结构设计思路

模型 `SimpleCNN` 的结构为：

```text
Conv(1→32) + BN + ReLU + Pool
Conv(32→64) + BN + ReLU + Pool
Conv(64→128) + BN + ReLU
GAP
FC(128→256) + ReLU + Dropout
FC(256→12)
```

#### 4.3.1 三层卷积的角色分工

前两层卷积后接池化，目的是逐步扩大感受野、降低空间分辨率，同时保留主要笔画结构。第三层卷积不再池化，是因为此时特征图已经降到 `7 x 7`，如果继续池化，空间信息会被压缩得过早，不利于区分结构相近的字符。

#### 4.3.2 BatchNorm 与 ReLU 的组合

每个卷积块都采用 `Conv + BN + ReLU`。其中：

- 卷积负责提取局部模式；
- BN 使中间特征分布更稳定，减轻不同层之间的尺度漂移；
- ReLU 提供稀疏非线性，提高表达能力与训练效率。

这组搭配在中小型 CNN 中非常常见，因为它兼顾了表达能力和优化稳定性。

#### 4.3.3 Global Average Pooling 的设计意义

模型没有在卷积后直接接一个大规模全连接层，而是先做 `AdaptiveAvgPool2d(1)`。这一步的意义主要有两点：

1. 将每个通道压缩成一个全局响应值，使模型更关注“某类特征是否出现”，而不是过度依赖其精确位置；
2. 显著减少全连接层参数量，降低过拟合风险。

对于字符分类，这种“先提局部模式，再做全局聚合”的思路是合理的，因为很多类别差异体现在笔画组合方式，而不是某个像素的精确坐标。

### 4.4 训练策略分析

CNN 训练采用：

- 优化器：`AdamW`
- 学习率调度：`CosineAnnealingLR`
- 损失函数：`CrossEntropyLoss(label_smoothing=0.1)`
- 正则化：`weight_decay=1e-4`、`Dropout(0.5)`、`BatchNorm`

这里的设计逻辑与 BP 部分明显不同。

首先，CNN 参数更多、层次更深，使用 `AdamW` 能在训练初期更快适应不同参数尺度；`AdamW` 将权重衰减与自适应更新拆开处理，也更适合现代卷积网络训练。

其次，余弦退火学习率让学习率从较大值平滑衰减到较小值，可以避免分段衰减带来的突变，对 100 轮左右的训练预算较友好。

最后，标签平滑并不是单纯“让标签变软”，它本质上是在抑制模型对单一类别产生过度自信，从而提高泛化稳定性。这一点在后面的消融中也有所体现。

### 4.5 实验结果

主训练结果为：

- 最优验证准确率：`99.91%`
- 末轮验证准确率：`99.8%`
- 训练配置：`epochs=100, batch_size=64`

与 BP 相比，CNN 的验证精度显著更高，且最优值与末轮值接近，说明训练更加稳定。

### 4.6 消融实验分析

CNN 消融结果如下：

| 配置 | 最优验证准确率 |
|---|---:|
| `full` | `99.82%`（epoch 59） |
| `no_aug` | `99.82%`（epoch 73） |
| `no_dropout` | `99.82%`（epoch 59） |
| `no_weight_decay` | `99.82%`（epoch 68） |
| `no_scheduler` | `99.82%`（epoch 59） |
| `no_label_smoothing` | `99.73%`（epoch 49） |

这个结果表面上看差异不大，但不能简单得出“这些组件都没有作用”的结论。更合理的理解是：当前数据集规模不算大、任务相对集中、基础 CNN 结构已经足够匹配问题，因此许多改进项的收益主要体现在训练稳定性、达峰过程和泛化边际，而不是体现在大幅提升最终准确率。

其中最值得注意的是 `no_label_smoothing` 略低，说明标签平滑确实能带来更稳的泛化。其余几项峰值并列，说明当前模型对这些改动不算高度敏感，但并不意味着它们没有理论意义。特别是在换随机种子、换划分或面对更复杂数据时，这些设计往往仍会体现出价值。

### 4.7 参数对比实验分析

CNN 学习率对比结果如下：

| 学习率 | 最优验证准确率 | 达峰 epoch | 末轮验证准确率 |
|---|---:|---:|---:|
| `1e-3` | `99.82%` | 80 | `99.73%` |
| `2e-3` | `99.82%` | 68 | `99.73%` |
| `5e-4` | `99.64%` | 46 | `99.46%` |

这里 `1e-3` 与 `2e-3` 的峰值并列，但 `1e-3` 达峰更晚，说明优化过程更平滑；`5e-4` 则略显保守，没有充分利用 100 轮训练预算。因此主模型默认学习率选择 `1e-3` 更稳妥。

## 5. Bonus 部分详细说明

根据 `PJ1.pdf`，Bonus 包含两个方向：

1. 防止过拟合；
2. 尝试不依赖深度学习框架、手动实现 CNN。

本仓库实际重点完成的是第一项 Bonus：防止过拟合。第二项“手写 CNN 卷积算子”并未单独展开为完整实验主线，因此以下说明主要围绕已完成的 Bonus 内容展开，并对未展开部分作出说明。

### 5.1 已完成的 Bonus：防止过拟合

当前 CNN 中用于抑制过拟合的核心机制包括：

1. 数据增强；
2. Batch Normalization；
3. Dropout；
4. Weight Decay；
5. Label Smoothing；
6. 相对克制的网络规模设计。

#### 5.1.1 数据增强

数据增强的目标，是在标签不变的前提下扩大训练分布，使模型不要把“训练集中恰好出现的具体位置、角度、尺度”当成必须记住的信息。对手写字符来说，轻微旋转、平移、缩放都可能来自真实书写差异，因此适度仿射增强有助于模型学习更鲁棒的类别特征。

需要强调的是，增强不是越强越好。若变换过大，就会破坏字符结构本身。因此代码中使用的是较克制的增强幅度，而不是大范围随机扭曲。

#### 5.1.2 Batch Normalization

BN 的直接作用是对中间特征做标准化，使每层输入分布更稳定。它带来的收益不仅是“训练更快”，还包括：

1. 降低不同层之间数值尺度波动；
2. 让较大学习率下的训练更稳定；
3. 在一定程度上形成轻微正则化效果。

对当前 CNN 而言，BN 使三层卷积块的训练更加平滑，也为后续使用 `AdamW + CosineAnnealing` 提供了更稳定的特征基础。

#### 5.1.3 Dropout

Dropout 放在全连接分类头中，概率设为 `0.5`。其核心思想是：训练时随机屏蔽部分隐藏单元，迫使模型不要依赖少数固定通路完成判别，而是学习更分散、更冗余的特征表示。

本任务中 Dropout 的消融没有带来明显峰值差异，这说明卷积主干本身已经非常强，分类头参数规模也不算大，因而 Dropout 的收益更多体现在安全边际上，而非决定最终上限。

#### 5.1.4 Weight Decay

Weight decay 通过惩罚过大的权重，抑制模型把决策边界拟合得过于尖锐。对于字符分类任务，它可以理解为一种“限制模型过度记忆训练样本局部噪声”的手段。

当前消融中去掉 `weight_decay` 后峰值几乎不变，说明该数据集上的卷积结构已经足够有效，参数并未严重失控。但从训练原则上看，保留一个温和的 `1e-4` 仍是更稳妥的选择。

#### 5.1.5 Label Smoothing

标签平滑是当前 Bonus 设计里最值得强调的一项，因为它在消融中确实表现出可观差异。标准 one-hot 标签会鼓励模型把正确类概率尽量推到 1，而标签平滑会保留一小部分概率质量给其他类，从而降低模型过度自信的问题。

对手写汉字这类类别间存在相似笔画结构的任务，标签平滑尤其合理。因为某些样本即使人工可辨，特征上也可能和相邻类别十分接近。让模型保留适度不确定性，往往比强行输出极端置信度更有利于泛化。

#### 5.1.6 结构规模控制本身也是防过拟合

除了显式正则项，网络设计本身也承担了防过拟合作用。当前 CNN 只使用三层卷积主干，并通过 `GAP` 代替大规模特征图直接展平，这显著减少了参数量。也就是说，Bonus 并不只是“额外挂几个正则化模块”，而是从结构层面主动控制模型复杂度。

### 5.2 为什么 Bonus 消融差异不大

从实验结果看，除了标签平滑外，其余组件的峰值准确率几乎相同。这并不矛盾，原因主要有三点：

1. 数据集规模和任务难度使得基础 CNN 已经足够强；
2. 多种正则化机制存在功能重叠，单独去掉某一项时，其他项仍能提供保护；
3. 单次划分、单随机种子下，某些改进更多反映在稳定性而不是单点峰值上。

因此，对 Bonus 的理解不能停留在“有没有提高 0.5% 准确率”，而应看到这些机制在训练稳定性、过置信抑制和结构复杂度控制上的作用。

### 5.3 未展开的 Bonus：手动实现 CNN

`PJ1.pdf` 的另一项 Bonus 是尝试不依赖 `PyTorch` 等深度学习框架手动实现 CNN。当前仓库没有把这一方向作为主实验内容单独完成，原因是本项目的重点放在：

1. 第一部分完整手写 BP，确保对反向传播原理的掌握；
2. 第二部分集中分析卷积网络结构设计与训练策略。

如果后续继续扩展，这一方向可以从最基础的单通道卷积、池化和卷积反向传播推导入手，再逐步替换现有框架组件。但就当前版本而言，Bonus 的主要完成内容是“防止过拟合”的系统设计与实验分析。

## 6. 两类模型的比较与讨论

分类任务结果对比如下：

| 模型 | 验证准确率 | 说明 |
|---|---:|---|
| BP（主训练） | `96.76%` | 全连接网络，输入展平 |
| BP（消融最优） | `97.21%` | `bp_leaky_relu` |
| CNN（主训练） | `99.91%` | 卷积网络 |
| CNN（消融最优） | `99.82%` | `full` |

两类模型的差距本质上不是“参数多少”的差距，而是结构先验的差距。

BP 网络把图像当作普通向量处理，需要依靠大量参数去间接恢复局部笔画关系；CNN 则直接利用局部连接和参数共享去建模空间结构，因此在字符分类上更高效、更自然，也更容易达到高精度。

换句话说，第一部分主要说明“只靠反向传播和全连接层，问题已经可以被解决”；第二部分则说明“当网络结构与任务统计规律匹配时，性能会进一步明显提升”。

## 8. 总结

本项目完整实现了两条技术路线：一条是纯 `numpy` 的反向传播全连接网络，一条是面向图像任务的卷积神经网络。

第一部分的重点在于把反向传播算法真正落到代码细节中，包括缓存中间量、逐层链式求导、稳定初始化、动量更新与梯度裁剪。第二部分的重点则在于理解为什么卷积结构更适合字符图像，以及为什么抗过拟合设计应同时体现在数据、损失、优化和网络结构四个层面。

实验结果表明，BP 网络已经能够达到较高分类精度，但 CNN 由于更符合图像的空间结构，最终取得了更高且更稳定的验证准确率。Bonus 部分进一步说明，高性能模型并不只靠加深网络获得，更重要的是在设计时控制模型复杂度，并通过合适的正则化机制提升泛化能力。
